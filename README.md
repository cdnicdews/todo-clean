# Todo App

Список задач на React + TypeScript + Vite + Supabase.

## Стек

- React 18
- TypeScript
- Vite
- Supabase (база данных)

## Функции

- Загрузка задач из Supabase при открытии страницы
- Добавление задачи (пустая задача не добавляется)
- Отметка задачи выполненной (визуально зачёркивается)
- Удаление задачи
- Все изменения сохраняются в Supabase и остаются после перезагрузки
- Индикатор загрузки и сообщение об ошибке
